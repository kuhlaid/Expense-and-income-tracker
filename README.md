# About this app.

This app. was entirely build using Google AIStudio. Some code lines were removed to fix issues but AIStudio built out everything. I began by prompting for database configurations and then asked for a few UI updates.

The reason I had this app. created was to track my expenses and basic income for planning purposes but primarily to log expenses using tagging (which is convoluted to try to accomplish using a spreadsheet). Using a relational database makes for much cleaner data organizing and queries. As I make updates to the app. within AIStudio I will copy the code to this repository for others to use. If you are wanting to use the code, you could fork the repository and then import into AIStudio and prompt it to make updates to the app. to meet your specs. or write the code yourself. The AIStudio database and web hosting greatly simplifies the process.
